# AI Resume Chatbot
## URL: https://ask-me-about-mohamed.streamlit.app/
An AI-powered resume chatbot built using Retrieval-Augmented Generation (RAG) with LangChain, FAISS, OpenAI, and Streamlit.

The application allows users to ask questions about my background, technical skills, projects, experience, and career interests using natural language.

## Features

- AI-powered resume Q&A
- Semantic search using vector embeddings
- Retrieval-Augmented Generation (RAG)
- Custom Streamlit UI
- Dockerized deployment
- Designed for cloud deployment and portfolio integration

## Tech Stack

- Python
- Streamlit
- OpenAI API
- LangChain
- FAISS
- Docker
